# Agile&Co
A board + online game where you manage an agile software development company, tackle real-world challenges, and lead your team to success. 

# Board Game
The game is primarily designed as an in-person card game.

The game is _print & play_. All materials and rules are available on the [game web site](https://agile-and-co.mnt.space).

# Online game
An online version for [Board Game Arena](https://boardgamearena.com/) is under development.
